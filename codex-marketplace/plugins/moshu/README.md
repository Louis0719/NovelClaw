# 墨枢 · Moshu

> 「让AI像人一样写网文，而不是像AI一样写网文。」

## 简介

墨枢（mòshū）是中文网文爆款写作的多Agent协同系统，专注于番茄/七猫/17K等平台的爆款方法论与去AI味润色。

## 能力清单

- 🏗️ **多Agent协同**：建筑师/写手/验证/审计四角色分离
- 📖 **爆款方法论**：30字卖点 + 200字故事核 + 五幕大纲
- 🚫 **去AI味检测**：20项AI味检测标准
- 📊 **评审打分**：9维度淘汰制 + 7维度雷达图
- 🧠 **记忆感知**：章节上下文自动继承，角色关系全局一致

## 安装

```bash
# 1. 添加 NovelClaw marketplace
codex plugin marketplace add https://github.com/Louis0719/NovelClaw --sparse codex-marketplace

# 2. 安装墨枢
codex plugin add moshu@novelclaw-marketplace
```

## 触发条件

**主动触发：** "写小说"、"继续写第X章"、"去AI味"、"评审"、"润色"
**被动触发：** 提到章节/大纲/角色/人设/爽点/钩子/世界观
