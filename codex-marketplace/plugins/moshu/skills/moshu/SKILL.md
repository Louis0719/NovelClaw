# 墨枢 v2.2.0

> 「让AI像人一样写网文，而不是像AI一样写网文。」

## 触发条件

**主动触发（精确匹配）：**
- 完整指令：`写小说`、`写网文`、`继续写第X章`、`帮我写第X章`
- 检测指令：`去AI味`、`自查第X章`、`AI味检测`、`量化打分第X章`
- 改写指令：`aggressive改写第X章`、`standard改写第X章`、`minimal改写第X章`

**被动触发（语义匹配，避免误判）：**
- ✅ 触发：章节 / 大纲 / 人设 / 角色 / 爽点 / 虐点 / 章末钩子 / 世界观 / 五幕结构 / 故事核
- ❌ 不触发（容易混淆的通用词）："优化"、"帮我" → 必须搭配上述关键词才触发

**反例（避免误判的常见错误）：**
- "帮我优化这段代码" → 不触发（无章节/小说相关关键词）
- "写一下工作计划" → 不触发（无网文/小说关键词）
- "帮我润色下这段宣传文案" → 询问用户是否要改小说章节

## 第一部分：写作流程

### 流程A：新书立项

```
① 目标平台？（番茄/七猫/起点/QQ阅读/其他）
② 题材类型？（都市/古言/系统/玄幻/现言/总裁/校园/其他）
③ 更新节奏？（日更/隔日更/周更）
```

确认后输出立项包：**30字卖点 + 200字故事核 + 五幕大纲 + 核心人设卡**，再生成前3章细纲。

---

### 流程B：章节写作

**第1步 — 读状态（有限降级）**

按以下顺序查找项目文件，找到就读，找不到走**最多 2 步降级**：

```
优先路径：
1. {project_root}/.moshu/world_state.json  ← 首选
2. {project_root}/world_state.json          ← 兼容
3. {project_root}/角色档案.md              ← 降级 1
4. {project_root}/大纲.md                   ← 降级 2

错误兜底（4 个文件全找不到时）：
→ 暂停写作流程，提示用户：
  "未找到项目记忆文件。请先执行以下任一操作：
   1. 跑 'moshu立项' 创建新书项目
   2. 指定已存在的小说项目路径
   3. 加载用户提供的状态文件"
→ 不再无限降级，避免基于错误猜测动笔
```

**第2步 — 构思确认（动笔前必做）**

```
• 本章核心事件是什么？（一件事推进）
• 情绪走向：起点 → 终点（要有起伏）
• 章末钩子：留什么让读者必须点下一章？
• 有没有要回收的伏笔？（查 伏笔追踪.md）
```

**第3步 — 动笔**

```
• 对话先写动作/表情，再写说的话
• 每段写完自问：这句话有没有推进剧情/情绪/人物？
• 避免先写心理再补动作
```

**第4步 — 去AI味自检（写完必做）**

执行「第二部分」检测，输出**量化分数 + 问题清单 + 推荐档位**，P0 全部修复，P1 修复 60%，P2 不强制。

**第5步 — 更新记忆银行**

```
• world_state.json：当前章节+1，人物状态更新，伏笔追踪表同步
• 伏笔追踪.md：新伏笔追加到表格，重要伏笔标注 "中期提示" 位置
• writing_state.cumulative_p*_fixed：累计修复数 +1
```

### 流程C：去AI味量化打分（v2.2.0 新增）

当用户说"打分"、"量化"、"AI味分数"时执行：

```
Step 1 — 加载正文 → 切分为段（按 \n\n 分割）
Step 2 — 跑 14 项 P0/P1/P2 检测器（每个返回 0-1 置信度）
Step 3 — 加权汇总：AI味密度 = P0*0.5 + P1*0.3 + P2*0.2
Step 4 — 输出：
  - 总分 0-100（100 = 完全是 AI 味，0 = 完全自然）
  - 7 维度雷达图（节奏 / 词汇 / 句式 / 比喻 / 心理 / 细节 / 风格）
  - 命中问题 Top 5 段落（含位置 + 触发规则 + 修复建议）
```

### 流程D：去AI味自查（保留，向后兼容）

当用户说"自查第X章"、"去AI味"时执行流程 C。

## 第二部分：去AI味检测系统（v2.2.0 升级版）

### 检测器说明

每个检测器返回 `(score, matches)`：

- **score**: 0.0-1.0 置信度（越高越像 AI）
- **matches**: 命中位置 + 触发规则 + 修复建议

### P0 — 致命伤（每条 1.0 分，立刻删/改）

#### ① 元叙事残留（meta-leak detector）

❌ 删掉这些：
- `[此处省略xxx字]`、`[内容已屏蔽]`、`[审核中]`
- `上一章提到`、`后文会出现`、`前情提要`
- `作者有话说`、`作者君`、`作者笔下的`
- `三天后`、`一周后`（无具体日期替代）→ 用 `腊月十三` / `三月初八`
- `男主/女主/女配/男配`（用角色名）→ 用 `萧衡` / `顾晚宁`

#### ② 系统文套路过重（system-cliché detector）

❌ 每章出现 **≥3 次** 触发高权重（1.0）：
- `叮，检测到……`、`系统提示：`、`叮咚！`
- `恭喜宿主获得……`、`温馨提示：`
- `任务完成，奖励发放中……`

❌ 出现 1-2 次 触发中权重（0.5）→ 修建议保留但要稀释
✅ **每章 ≤1 次** 才安全

#### ③ 都市文套路过重（urban-cliché detector）

❌ 每章出现 **≥3 次**：
- `少爷`、`夫人`、`管家`（非豪门场景）
- `女人，你成功引起了我的注意`
- `她是我的女人，谁也不准动`
- `合同到期，我们离婚吧`

#### ④ 结尾套话（ending-cliché detector）

❌ 章末禁止出现（任意一次就扣 1.0）：
- `欲知后事如何，请看下回分解`
- `未完待续`、`待续`、`（未完）`
- `作者君要去吃饭了……`
- `感谢观看`、`感谢阅读`、`感谢支持`

#### ⑤ 知乎/公众号腔（essay-cliché detector）

❌ 网文里绝对不能出现（任意一次就扣 1.0）：
- `首先……其次……最后……`
- `综上所述`、`总的来说`、`简而言之`
- `值得注意的是`、`不可否认的是`、`显而易见的是`
- `作为一个……`、`站在……的角度`

### P1 — 明显AI味（每条 0.3 分，发表前必改）

#### ⑥ 必杀词表（vocabulary detector）

**高危动词（直接换）：**

| 原词 | 替换为 | 置信度 |
|------|--------|--------|
| 深吸一口气 | 顿了一下 | 0.9 |
| 双拳紧握 | 攥紧了拳头 | 0.9 |
| 瞳孔剧烈收缩 | 眼睛瞪大 | 0.95 |
| 心脏狂跳 | 胸口发紧 | 0.9 |
| 眼泪在眼眶里打转 | 眼眶发热 | 0.85 |
| 不由自主 | 没忍住 | 0.8 |
| 情不自禁 | 没防备 | 0.8 |
| 难以置信 | 愣住 | 0.7 |
| 缓缓开口 | 张了张嘴 | 0.7 |
| 眉头紧锁 | 皱了下眉 | 0.7 |

**高危形容词（直接换/省掉）：**

| 原词 | 处理方式 | 置信度 |
|------|----------|--------|
| 精致的 | 直接描写外貌（窄眼/柳叶眉/薄唇） | 0.85 |
| 冰冷的 | 冷得像刀/手心发凉 | 0.85 |
| 温柔的 | 动作支撑（给她倒了杯温水） | 0.85 |
| 绝美的容颜 | 省掉，用"好看"或具体描写 | 0.95 |
| 倾国倾城 | 省掉 | 0.95 |
| 邪魅一笑 | 嘴角一勾 | 0.95 |
| 俊美无涛 | 省掉 | 0.95 |
| 高大威猛 | 写身高（八尺二寸）+ 肩宽 | 0.9 |

**高危副词（直接删/换）：**

| 原词 | 处理方式 | 置信度 |
|------|----------|--------|
| 非常、极其、格外、异常 | 直接删或换具体感受 | 0.7 |
| 简直 | 直接删 | 0.85 |
| 竟然、居然 | 删或改"没想到" | 0.6 |
| 仿佛、似乎、好像 | 全章 ≤3 次 | 0.5 |
| 顿时、骤然、蓦然 | 删 | 0.85 |

**无意义开头（段落开头时直接删，置信度 0.6）：**
`事实上`、`实际上`、`其实`、`大家知道`、`众所周知`、`你可能不知道`、`最关键的是`、`不得不说`

**无意义结尾（直接删，置信度 0.7）：**
`事情就是这样`、`我只能说这么多`、`懂的都懂`、`就这么简单`

#### ⑦ 节奏均匀（rhythm detector）— v2.2.0 量化

```
检测算法（伪代码）：
  sentences = split_by_punctuation(text)
  lengths = [len(s) for s in sentences]
  variance = std(lengths) / mean(lengths)  # 变异系数
  
  if 0.85 ≤ variance ≤ 1.15:
    flag("rhythm-uniform")  # 太均匀，AI 嫌疑
    suggest("穿插 3-7 字短句和 40+ 字长句")
  
  if variance < 0.7:
    flag("rhythm-rigid")  # 极均匀，硬模板
    suggest("打散整段，重新组织")
```

#### ⑧ 词汇轮换陷阱（lexicon-rotation detector）— v2.2.0 词表

**常见 AI 词轮换组**（同段出现 ≥2 个就扣分）：

| 词组 | 替代 |
|------|------|
| 微笑/嘴角轻扬/唇边泛起笑意 | 笑了一下 / 嘴角一勾 / 咧嘴 |
| 看着/凝视/注视/盯着 | 看 / 瞥 / 抬眼 |
| 说/开口/缓缓说道/轻声道 | 说 / 开口 / 道 |
| 走/迈步/缓步/踱步 | 走 / 迈腿 / 抬脚 |
| 心里想/心想/内心暗道 | 省掉，用动作外化 |
| 点了点头/颔首/微微点头 | 点了下头 |
| 转身/转过头/回过身 | 转头 / 转过来 |
| 沉默/沉默片刻/沉默不语 | 没说话 / 不吭声 |
| 叹了口气/轻叹一声/长叹 | 叹了声 |
| 皱眉/蹙眉/眉头微皱 | 皱了下眉 |

```
❌ "他微微一笑、嘴角轻扬、唇边泛起笑意"
✅ "他笑了一下，嘴角扬起来"

❌ "她凝视着远方，心里想……"
✅ "她看着远处，攥紧了手指"
```

#### ⑨ 过渡词堆砌（transition detector）

检测算法：一段连续出现 **≥3 个** `于是、然后、接着、与此同时、此外、而且、不过、可是、然而、因此、所以`

修正：用动作/时间线/对话代替连接词
```
❌ "于是他走了过去，然后坐了下来，接着拿起茶杯"
✅ "他走过去坐下，拿起茶杯。"
```

#### ⑩ 对话标签单调（dialog-tag detector）

检测：连续 3 段对话都用 `他说/她说/XX 道/XX 说道` 收尾 → 扣分

```
❌ "你怎么了？"她担心地说。
   "我没事。"他勉强笑了笑说。
   "你骗人！"她生气地说。

✅ 动作+台词交织：
   "你怎么了？"她攥紧杯子。
   他没答话，只是看着她。
   "我在跟你说话！"她把杯子往桌上一搁。
```

---

### P2 — 润色项（每条 0.1 分，有余力再改）

#### ⑪ 心理活动过载（psyche-overflow detector）

检测：连续 2 段以上全是"她想"、"她觉得"、"她心里"；单次心理独白 >100 字

修正：动作/表情外化，不要让读者看"内心OS"

#### ⑫ 爽点/虐点无铺垫（emotion-pacing detector）

检测：情绪爆发前 200 字内无情绪积累

#### ⑬ 具体感不足（concreteness detector）

检测：通篇"很多、很好、非常喜欢他"

修正：数字、名字、场景比形容词更有说服力
```
❌ "受到了很大的欢迎"
✅ "评论区涌入三千条催更"
```

#### ⑭ 比喻过重/过新（metaphor-overload detector）

检测：每段 ≥1 个新比喻；同一比喻同章出现 2 次以上 → 扣分

## 第三部分：v2.2.0 新增能力

### 🆕 能力 1：量化打分（0-100）

**计算公式**

```
ai_density_score = (p0_hits * 1.0 + p1_hits * 0.3 + p2_hits * 0.1) * (chapter_length / 3000)

归一化到 0-100：
  score_100 = min(100, ai_density_score * 20)

评分等级：
  0-20  → 🟢 自然（可直接发布）
  21-40 → 🟡 微 AI 味（小修）
  41-60 → 🟠 中 AI 味（standard 档改写）
  61-80 → 🔴 重 AI 味（aggressive 档改写）
  81-100 → ⚫ 极 AI 味（重写全章）
```

### 🆕 能力 2：7 维度雷达图

```
        节奏 (rhythm)
           ▲
          /|\
   风格 / | \ 词汇
      /  |  \
    /   |   \
 比喻 ──+── 句式
    \   |   /
      \ |  /
   心理 \|/ 细节
           ▼

每个维度 0-100 分，越低越自然
```

### 🆕 能力 3：作者风格指纹（v2.2.0 突破）

**用法**：用户提供一段自己写的文字（任意 500-2000 字），墨枢提取风格特征：

- 平均句长 + 分布（偏短句/中等/长句）
- 高频动词 + 形容词
- 比喻风格（具象/抽象/不用比喻）
- 对话占比
- 心理描写占比
- 段落开头偏好（动作/对话/环境/心理）

**效果**：写新章节时，墨枢自动采样该风格，写出来的句子和作者本人更像。

### 🆕 能力 4：LLM 水印识别（v2.2.0 论文级）

借鉴 Google DeepMind 2023 论文《Scalable watermarking》，识别 LLM 自带的 token 分布偏向：

- 低频 token 比例异常低（LLM 偏好高频词）
- 句末标点分布偏向均匀（人类更随机）
- 特定短语重复模式（"值得注意的是"、"简而言之"）
- 连词分布偏向均匀

→ 输出 LLM 水印置信度，让用户知道"这段到底是不是 AI 写的"

### 🆕 能力 5：真人对照改写（v2.2.0 创新）

**用法**：

```
Step 1 — 用户提供"自己写的对照样本"（500+ 字）
Step 2 — 用户说"按我的风格改写第X章"
Step 3 — 墨枢：
  a. 提取作者风格指纹
  b. 对章节逐段分析（人写 vs AI 写 的差异点）
  c. 按作者风格重写
Step 4 — 输出：对照表（人写示例 → AI 重写版本）
```

## 第八部分：核心原则

**① 有钩子**
章末：悬念/留白/话头，让读者必须点下一章

**② 有节奏**
一紧一松，一喜一悲，不要全程高能或全程平淡

**③ 有具体**
数字、名字、场景描写，比形容词更有说服力

**④ 有立场**
主角的观点/喜好/判断要清晰，读者要能站队

**⑤ 有记忆点**
每章至少有一个让人记住的细节（动作/对话/梗）

## 第九部分：使用示例

**示例 1：用户说"帮我写一个追妻火葬场"**
```
→ 问清楚：平台/题材/更新节奏
→ 输出立项包：30字卖点 + 200字故事核 + 五幕大纲 + 人设卡
→ 确认后生成前3章细纲
→ 写第1章：构思 → 动笔 → 去AI味自检 → 更新 world_state.json
```

**示例 2：用户说"打分第5章"**
```
→ 加载第5章
→ 跑14项检测器（v2.2 算法）
→ 输出：0-100 分 + 7维雷达 + Top 5 命中点
→ 不自动改，等用户确认
```

**示例 3：用户说"按我的风格改写第3章"**
```
→ 加载作者风格指纹（author_style.json）
→ 加载第3章
→ 逐段分析（人写 vs AI 写的差异）
→ 按作者风格重写
→ 输出对照表 + 改写版本 + 前后分数对比
```

**示例 4：用户说"aggressive改写第3章"**
```
→ 加载章节正文
→ 执行全量 P0+P1+P2 检测
→ aggressive 重写（重写段落结构 + 调整句长 + 补充细节）
→ 输出改写版本 + 修改摘要 + 前后分数对比
```

## 第十部分：错误处理（v2.2.0 新增）

| 错误情况 | 兜底动作 |
|---------|---------|
| 4 个项目记忆文件全找不到 | 暂停写作，提示用户跑"立项"或指定项目路径 |
| `world_state.json` JSON 损坏 | 自动备份为 `.broken-{timestamp}`，提示用户检查 |
| `templates/` 目录不存在 | **不再发生**（v2.2.0 已内置 templates/） |
| Codex CLI 版本 < 0.142.5 | 提示：`请先运行 codex update` |
| LLM 改写出错（返回空/截断） | 重试 1 次，仍失败则报告章节号 + 错误信息，等用户决策 |
| 量化打分输入 <100 字 | 警告："文本太短，打分不准（置信度低），建议至少 500 字以上" |
