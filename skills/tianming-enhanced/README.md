# 天命增强层 · TianMing Enhanced Layer

> 天命核心系统的三大增强模块，专注于审稿、适配与合规。

---

## 一、补齐了什么

| 短板 | 增强模块 | 触发指令 |
|---|---|---|
| 无人工逐字审稿 | 审稿协议 | `「天命：审稿 | 卷1 第3章」` |
| 无平台投稿格式检查 | 平台适配 | `「天命：适配 | 番茄」` |
| 无内容合规审核 | 合规审查 | `「天命：合规 | 卷1」` |

---

## 二、完整工作流

```
「天命：大纲」→「天命：规划」→「天命：目录」→「天命：正文」
       ↓
「天命：体检」← 天命核心系统
       ↓
「天命：审稿 | 卷1 第3章」 ← 天命增强层
       ↓
「天命：审稿全文 | 卷1」 ← 天命增强层（批量审稿）
       ↓
「天命：合规 | 卷1」 ← 天命增强层
       ↓
「天命：适配 | 番茄」 ← 天命增强层
       ↓
✅ 前往平台投稿
```

## 三、各模块说明

### 审稿协议（review.md）

逐段扫描正文，检查：
- 逻辑漏洞（设定前后矛盾）
- 对话不符合角色档案
- 节奏断层（无过渡的跳跃）
- 伏笔引用准确性
- 标点/错别字/病句

输出：结构化「审稿报告」，分【严重】【建议】【优化】三级。

---

### 平台适配（adapt.md + platform-standards.md）

内置番茄小说、起点中文、晋江文学、飞卢小说四大平台规范：

| 平台 | 核心规范 |
|---|---|
| **番茄小说** | 前三章钩子密度≥3/章、1800-2200字/章、标题党过滤 |
| **起点中文** | 书名≤14字、简介≤100字、开篇2000字黄金圈 |
| **晋江文学** | 言情/剧情线比例、敏感词过滤、封面文案格式 |
| **飞卢小说** | 前3章2-3个小高潮、日更≥4000字、节奏快 |

---

### 合规审查（compliance.md + compliance-check.md）

三层过滤：
1. **基础层**：内置涉黄/涉政关键词库（≥500词），命中即标红
2. **进阶层**：腾讯云内容安全API / 阿里云绿网 / 网易易盾 自动过检
3. **人工层**：生成「合规风险报告」，高风险段落人工复核

## 四、部署方式

将整个 `tianming-enhanced/` 目录与 `tianming-novel-system/` 放在同一父目录下：

```
openclaw/workspace/skills/
├── tianming-novel-system/    ← 天命核心（先加载）
└── tianming-enhanced/        ← 天命增强（后加载）
```

**加载顺序**：先初始化天命核心系统（`「初始化」`），再使用增强层指令。

---

## 五、维护说明

- **关键词库**：每季度更新一次，参考各平台最新审核规则
- **平台规范**：各平台政策变化后及时更新 `codex/platform-standards.md`
- **API集成**：合规API需执笔者自行申请密钥，填入 `codex/compliance-check.md` 相应位置
