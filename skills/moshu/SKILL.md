# 墨枢 v2.1.0

> 「让AI像人一样写网文，而不是像AI一样写网文。」

## 触发条件

**主动触发：**
- "写小说"、"写网文"、"继续写第X章"、"帮我写"
- "去AI味"、"自查"、"帮我检查第X章"
- "润色"、"改写"、"优化"

**被动触发：**
- 提到章节/大纲/角色/人设/爽点/虐点/钩子/世界观

## 第一部分：写作流程

### 流程A：新书立项

```
① 目标平台？（番茄/七猫/起点/QQ阅读/其他）
② 题材类型？（都市/古言/系统/玄幻/现言/总裁/校园/其他）
③ 更新节奏？（日更/隔日更/周更）
```

确认后输出立项包：**30字卖点 + 200字故事核 + 五幕大纲 + 核心人设卡**，再生成前3章细纲。

---

### 流程B：章节写作

**第1步 — 读状态**

按以下顺序查找项目文件，找到就读，找不到就走降级流程：

```
优先路径：
1. {project_root}/.moshu/world_state.json
2. {project_root}/world_state.json
3. {project_root}/角色档案.md
4. {project_root}/大纲.md

降级流程（文件不存在时）：
→ world_state.json 缺失 → 从上一章结尾推断当前状态
→ 角色档案.md 缺失 → 用立项包中的人设卡代替
→ 大纲.md 缺失 → 用立项包中的五幕大纲代替
```

**第2步 — 构思确认（动笔前必做）**

```
• 本章核心事件是什么？（一件事推进）
• 情绪走向：起点 → 终点（要有起伏）
• 章末钩子：留什么让读者必须点下一章？
• 有没有要回收的伏笔？
```

**第3步 — 动笔**

```
• 对话先写动作/表情，再写说的话
• 每段写完自问：这句话有没有推进剧情/情绪/人物？
• 避免先写心理再补动作
```

**第4步 — 去AI味自检（写完必做）**

执行「第二部分」检测，P0 全部修复，P1 修复 60%，P2 不强制。

**第5步 — 更新记忆银行**

```
• world_state.json：当前章节+1，人物状态更新
• 伏笔追踪.md：新伏笔追加到表格
```

---

### 流程C：去AI味自查

当用户说"自查第X章"、"去AI味"、"帮我检查"时执行：

```
Step 1 — 快速扫描 P0（1分钟）
Step 2 — 深度扫描 P1/P2（3-5分钟）
Step 3 — 输出问题清单 + 推荐档位（不改，等用户确认）
```

## 第二部分：去AI味检测系统

### P0 — 致命伤（立刻删/改）

#### ① 元叙事残留

❌ 删掉这些：
- `[此处省略xxx字]`、`[内容已屏蔽]`
- `上一章提到`、`后文会出现`、`前情提要`
- `作者有话说`、`作者君`、`作者笔下的`
- `三天后`、`一周后`（无具体日期替代）
- `男主/女主/女配/男配`（用角色名）

#### ② 系统文套路过重

❌ 每章出现3次以上：
- `叮，检测到……`、`系统提示：`
- `恭喜宿主获得……`、`温馨提示：`
- `任务完成，奖励发放中……`

修正：每章 ≤2次

#### ③ 都市文套路过重

❌ 每章出现3次以上：
- `少爷`、`夫人`、`管家`（非豪门场景）
- `女人，你成功引起了我的注意`
- `她是我的女人，谁也不准动`
- `合同到期，我们离婚吧`

#### ④ 结尾套话

❌ 章末禁止出现：
- `欲知后事如何，请看下回分解`
- `未完待续`、`待续`
- `作者君要去吃饭了……`
- `感谢观看`、`感谢阅读`

#### ⑤ 知乎/公众号腔

❌ 网文里绝对不能有：
- `首先……其次……最后……`
- `综上所述`、`总的来说`
- `值得注意的是`、`不可否认的是`

---

### P1 — 明显AI味（发表前必改）

#### ⑥ 必杀词表

**高危动词（直接换）：**

| 原词 | 替换为 |
|------|--------|
| 深吸一口气 | 顿了一下 |
| 双拳紧握 | 攥紧了拳头 |
| 瞳孔剧烈收缩 | 眼睛瞪大 |
| 心脏狂跳 | 胸口发紧 |
| 眼泪在眼眶里打转 | 眼眶发热 |
| 不由自主 | 没忍住 |
| 情不自禁 | 没防备 |
| 难以置信 | 愣住 |

**高危形容词（直接换/省掉）：**

| 原词 | 替换为 |
|------|--------|
| 精致的 | 直接描写外貌 |
| 冰冷的 | 冷得像刀 |
| 温柔的 | 动作支撑 |
| 绝美的容颜 | 省掉，用"好看" |
| 倾国倾城 | 省掉 |
| 邪魅一笑 | 嘴角一勾 |

**高危副词（直接删/换）：**

| 原词 | 处理方式 |
|------|----------|
| 非常、极其、格外、异常 | 直接删或换具体感受 |
| 简直 | 直接删 |
| 竟然、居然 | 删或改"没想到" |

**无意义开头（段落开头时直接删）：**
`事实上`、`实际上`、`其实`、`大家知道`、`众所周知`、`你可能不知道`、`最关键的是`

**无意义结尾（直接删）：**
`事情就是这样`、`我只能说这么多`、`懂的都懂`

#### ⑦ 节奏均匀

判断：随机读一段，每句15-22字、长度差异<5字 → ⚠️ AI节奏

修正：穿插超短句（3-7字）+ 超长句（40字+），打破整齐段落结构

#### ⑧ 词汇轮换陷阱

判断：同一段里同一个动作用了3个近义词 → ⚠️ AI词汇轮换

```
❌ "他微微一笑、嘴角轻扬、唇边泛起笑意"
✅ "他笑了一下，嘴角扬起来"
```

#### ⑨ 过渡词堆砌

判断：一段出现3个以上 `于是、然后、接着、与此同时、此外、而且`

修正：用动作/时间线代替连接词

#### ⑩ 对话标签单调

判断：`"他说"、"她说"` 每章出现3次以上且无变化

```
❌ "他笑着说"、"她哭着说"、"他叹了口气说"
✅ 动作+台词交织：
   "你怎么这样？"她攥紧杯子。
   他没答话，只是看着她。
   "我在跟你说话！"她把杯子往桌上一搁。
```

---

### P2 — 润色项（有余力再改）

#### ⑪ 心理活动过载

判断：连续2段以上全是"她想"、"她觉得"；单次心理独白>100字

修正：动作/表情外化，不要让读者看"内心OS"

#### ⑫ 爽点/虐点无铺垫

判断：情绪爆发来得太突然，没有积累

```
❌ AI写法：她很难过。然后男主道歉了。她突然就开心了。
✅ 正确写法：
   她低下头，睫毛颤了颤。
   想把那句话说出口，又咽了回去。
   男主开口了，声音有点哑。
   她没抬头，但耳朵竖了起来。
```

#### ⑬ 具体感不足

判断：通篇"很多、很好、非常喜欢他"

修正：数字、名字、场景比形容词更有说服力
```
❌ "受到了很大的欢迎"
✅ "评论区涌入三千条催更"
```

#### ⑭ 比喻过重/过新

判断：每段都有新比喻；同一比喻同章出现2次以上

## 第三部分：场景配置

| 场景 | 档位 | 重点 |
|------|------|------|
| 首发（番茄/七猫/起点） | standard | P0全检，P1检60%，P2不强制 |
| 润色（修改已有章节） | aggressive | 全量P0+P1，结构重整 |
| 自查（检测现有章节） | detect only | 输出问题清单，不改 |
| 大纲/人设（世界观构建） | minimal | 逻辑自洽、设定新颖 |

---

## 第四部分：改写档位

| 档位 | 适用范围 |
|------|----------|
| **minimal** | 只替换高频词，不动句式 |
| **standard** | 替换全部P0+P1问题词，调整过渡词 |
| **aggressive** | 重写段落结构，调整句长分布，补充具体细节 |

## 第五部分：输出格式

### 自查报告格式

```
【自查报告】Ch.X

■ P0致命伤（X处）
  1. [元叙事] 第X段："[此处省略...]" → 删
  2. [系统文] 第X段：连续3次"叮，检测到..." → 保留1次

■ P1明显问题（X处）
  1. [词汇] 第X段："深吸一口气" → 改"顿了一下"
  2. [节奏] 第X段：连续5句长度相近 → 穿插短句

■ P2润色项（X处）
  ...

■ 优先修改顺序
  ① 先改P0 → ② 再改P1 → ③ 最后P2

■ 总体评分
  AI味密度：██░░░（中）
  推荐档位：standard
```

### 完整改写输出

```
【AI味检测报告】Ch.X
P0：X处 / P1：X处 / P2：X处

【问题清单】
（见上方格式）

【改写版本】
（完整正文）

【修改摘要】
  · 替换词汇：X处
  · 删除元叙事：X处
  · 调整节奏：X处
  · 补充细节：X处
```

### 文件位置


## 第七部分：核心原则

**① 有钩子**
章末：悬念/留白/话头，让读者必须点下一章

**② 有节奏**
一紧一松，一喜一悲，不要全程高能或全程平淡

**③ 有具体**
数字、名字、场景描写，比形容词更有说服力

**④ 有立场**
主角的观点/喜好/判断要清晰，读者要能站队

**⑤ 有记忆点**
每章至少有一个让人记住的细节（动作/对话/梗）

## 第八部分：使用示例

**示例1：用户说"帮我写一个追妻火葬场"**
```
→ 问清楚：平台/题材/更新节奏
→ 输出立项包：30字卖点 + 200字故事核 + 五幕大纲 + 人设卡
→ 确认后生成前3章细纲
→ 写第1章：构思 → 动笔 → 去AI味自检 → 更新world_state.json
```

**示例2：用户说"自查第5章"**
```
→ 加载章节正文
→ 执行P0扫描（1分钟）
→ 执行P1扫描（3分钟）
→ 输出：问题清单 + 推荐档位
→ 不自动改，等用户确认
```

**示例3：用户说"帮我改第3章，aggressive模式"**
```
→ 加载章节正文
→ 执行全量检测
→ 执行aggressive改写
→ 输出改写版本 + 修改摘要
```
