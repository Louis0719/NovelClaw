# 质量评审标准（Quality Standards）

本文档从 `evaluator_agent.py` 和评审逻辑中提取墨枢的质量评审体系，包括评分维度、打分标准和决策逻辑。

---

## 评分维度体系

墨枢使用两套评分体系：

1. **EvaluatorAgent 评分**（5维度，0-1）
2. **JudgeAgent 裁决评分**（6维度，0-10）

---

## EvaluatorAgent 评分体系

### 评分维度

| 维度 | 字段名 | 类型 | 范围 | 权重 | 说明 |
|------|--------|------|------|------|------|
| 综合分数 | `overall_score` | float | 0.0-1.0 | 最高 | 综合质量评估 |
| 连贯性 | `coherence` | float | 0.0-1.0 | 高 | 文本内部逻辑自洽 |
| 新颖性 | `novelty` | float | 0.0-1.0 | 中 | 创意和独特性 |
| 逻辑性 | `logic` | float | 0.0-1.0 | 中 | 情节推进的逻辑合理性 |
| 节奏 | `pacing` | float | 0.0-1.0 | 中 | 叙事节奏把控 |
| 情绪力度 | `emotional_score` | float | 0.0-1.0 | 中 | 情感共鸣和感染力 |

### 各维度打分标准

#### overall_score（综合分数）

| 分数区间 | 等级 | 说明 |
|----------|------|------|
| 0.90 - 1.00 | 优秀 | 达到专业网文发表水准 |
| 0.75 - 0.89 | 良好 | 有小幅改进空间 |
| 0.60 - 0.74 | 可接受 | 基本可用，需小幅修订 |
| 0.40 - 0.59 | 较差 | 需要较大修改 |
| 0.00 - 0.39 | 很差 | 需要重写 |

#### coherence（连贯性）

| 分数区间 | 说明 |
|----------|------|
| 0.90-1.00 | 叙事流畅，无逻辑断层 |
| 0.75-0.89 | 基本连贯，有小幅不顺畅处 |
| 0.60-0.74 | 存在逻辑跳跃或重复 |
| 0.40-0.59 | 有多处逻辑矛盾或断层 |
| 0.00-0.39 | 叙事混乱，难以理解 |

**检测方法**：
- 事件因果链是否完整
- 人物行为是否有铺垫
- 场景转换是否有过渡
- 前后信息是否一致

#### novelty（新颖性）

| 分数区间 | 说明 |
|----------|------|
| 0.90-1.00 | 情节创新，有独特设定 |
| 0.75-0.89 | 有一定新意，套路较少 |
| 0.60-0.74 | 基本套路，但处理得当 |
| 0.40-0.59 | 套路明显，缺乏创新 |
| 0.00-0.39 | 完全套路化，无新意 |

**检测方法**：
- 情节桥段是否常见套路
- 设定是否有独特性
- 人物关系是否有新意
- 冲突设计是否有创新

#### logic（逻辑性）

| 分数区间 | 说明 |
|----------|------|
| 0.90-1.00 | 情节发展完全符合逻辑 |
| 0.75-0.89 | 基本合理，极少漏洞 |
| 0.60-0.74 | 有轻微逻辑漏洞 |
| 0.40-0.59 | 存在明显逻辑问题 |
| 0.00-0.39 | 逻辑混乱，自相矛盾 |

**检测方法**：
- 人物决策是否符合性格
- 事件发展是否有因果
- 能力体系是否前后一致
- 时间线是否清晰

#### pacing（节奏）

| 分数区间 | 说明 |
|----------|------|
| 0.90-1.00 | 节奏完美，张弛有度 |
| 0.75-0.89 | 节奏良好，稍有不足 |
| 0.60-0.74 | 节奏一般，部分拖沓或过快 |
| 0.40-0.59 | 节奏问题明显 |
| 0.00-0.39 | 节奏完全失控 |

**检测方法**：
- 高潮与铺垫的比例
- 场景详略是否得当
- 冲突升级是否有序
- 章节是否有明确的节奏变化点

#### emotional_score（情绪力度）

| 分数区间 | 说明 |
|----------|------|
| 0.90-1.00 | 情感充沛，感染力强 |
| 0.75-0.89 | 情感较充沛，有感染力 |
| 0.60-0.74 | 情感一般，感染力中等 |
| 0.40-0.59 | 情感平淡，感染力弱 |
| 0.00-0.39 | 缺乏情感，枯燥无味 |

**检测方法**：
- 情感描写是否具体生动
- 读者是否能产生共鸣
- 关键场景是否有情感张力
- 角色心理描写是否深入

## 通过阈值与决策逻辑

### 基础通过条件

```
overall_score >= 0.6
AND coherence >= 0.5
AND novelty >= 0.5
```

### 裁决流程

```
评估结果
    │
    ├── overall_score < 0.6
    │   └── 触发 Rewrite（重写）
    │
    ├── overall_score >= 0.6
    │   ├── coherence < 0.5 或 novelty < 0.5
    │   │   └── 触发 RealtimeEditor 针对性修改
    │   │
    │   └── coherence >= 0.5 AND novelty >= 0.5
    │       └── 通过，进入下一章或 Finalize
```

### 多轮迭代决策

```
Round 1: Writer → 评估 < 0.6
    ↓
Round 2: Rewrite → 评估 >= 0.6 但 coherence < 0.5
    ↓
RealtimeEditor 修复连贯性问题
    ↓
评估 >= 0.75（高质量）或 >= 0.6（可接受）
    ↓
Finalize
```

## JudgeAgent 裁决体系

### 六维度评分（0-10）

| 维度 | 说明 | 高分标准 | 低分标准 |
|------|------|----------|----------|
| **Relevance** | 与主题/需求的契合度 | 完全切题，精准回应 | 偏离主题 |
| **Coherence** | 叙事连贯性 | 结构清晰，逻辑通顺 | 结构混乱，逻辑断层 |
| **Empathy** | 情感共鸣 | 情感充沛，引发共鸣 | 情感平淡 |
| **Surprise** | 出人意料/反转质量 | 反转精彩，意外合理 | 平铺直叙 |
| **Creativity** | 创意独特性 | 设定独特，桥段新颖 | 套路明显 |
| **Complexity** | 叙事复杂度 | 层次丰富，深度充足 | 过于简单 |

### overall 计算方式

各维度等权平均：
```
overall = (Relevance + Coherence + Empathy + Surprise + Creativity + Complexity) / 6
```

### 裁决规则

```
if candidate_overall > reference_overall + 0.5:
    winner = "candidate"
elif reference_overall > candidate_overall + 0.5:
    winner = "reference"
else:
    winner = "tie"
```

### 备注要求

JudgeAgent 的 `notes` 字段必须包含：
1. 简要说明哪个候选更好
2. 各维度的主要差异

## 质量评审与其他模块的关系

```
EvaluatorAgent
    │
    ├── 触发 RealtimeEditor（当 coherence < 0.5 或其他维度明显不足）
    │
    ├── 触发 Rewrite（当 overall_score < 0.6）
    │
    ├── 触发 Judge（当多个候选 overall_score 接近）
    │
    └── 通过 → Finalize（当 overall_score >= 0.6 且 coherence >= 0.5）
```

## 评估提示词参考（中文模式）

EvaluatorAgent 的评估 prompt 要求：

```
请评估以下文本的新颖性、连贯性和情感一致性。
检查逻辑一致性和结构完整性。
提供具体的改进建议。
给出 0-1 之间的质量分数。
```

JudgeAgent 的 prompt 规则：
- 六维度各 0-10 分
- 必须输出 JSON 格式
- `notes` 必须包含裁决理由
- 简洁一致

| 场景 | 使用评审标准 |
|------|-------------|
| 单章生成完成 | EvaluatorAgent 评估 |

| 草稿发现问题 | RealtimeEditor + 一致性检查 |
| 章节推进判断 | TurningPointTracker |
| 全文质量评估 | 多轮 EvaluatorAgent 汇总 |
