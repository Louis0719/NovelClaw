# 去AI味检测标准（AI Taste Checker）

墨枢使用 RealtimeEditor 和 EvaluatorAgent 协作检测并修复文本中的 AI 感。本文档提取自 `realtime_editor.py` 和 `evaluator_agent.py`，列出完整的 20 项检测标准和修复方法。

## 各标准详解

### 1. 一致性冲突（Consistency Conflict）

**定义**：人物行为与已建立的性格设定、历史背景产生矛盾。

**检测方法**：
- 对比 MemorySystem 中存储的角色设定
- 检测行为是否符合 `entity_state` 中记录的性格特征
- 关键检测点：决策、对话反应、重要情节节点

**修复建议**：
```
请检查人物行为是否符合其性格设定，确保前后一致。
如需修改，请：
1. 回溯该人物的核心性格特征
2. 找出行为与性格的矛盾点
3. 修改行为使其符合人物弧线
```

---

### 2. 逻辑跳跃（Logical Jump）

**定义**：情节从一个状态突然跳到另一个没有因果关联的状态。

**检测方法**：
- 一致性检查器（ConsistencyChecker）检测事件因果链
- 识别缺少中间过渡状态的情节推进

**修复建议**：
```
请检查情节发展是否符合逻辑，确保前后连贯。
补充必要的因果链条和过渡状态。
```

---

### 3. 转折突兀（Abrupt Turning Point）

**定义**：重要情节转折缺乏情感铺垫或逻辑准备，令读者感到突然。

**检测方法**（`RealtimeEditor._check_if_abrupt`）：
```python
prompt = """请判断以下转折点是否突兀：
1. 缺乏铺垫
2. 过于突然
3. 不符合逻辑发展
回答：是/否，并简要说明原因。"""
```

**修复建议**：
```
请为转折点添加适当的铺垫：
1. 情感铺垫：增加情绪变化的过渡
2. 事件铺垫：引入导致转折的前置事件
3. 逻辑铺垫：补充因果关系的中间环节
```

---

### 4. 人物行为漂移（Character Drift）

**定义**：角色在故事发展中逐渐偏离其核心性格设定，行为变得不像该角色。

**检测方法**：
- 对照 `entity_state` 中记录的角色核心特征
- 检测关键时刻（冲突、决策）的行为一致性

**修复建议**：
```
人物变化需要有合理的铺垫和原因：
1. 识别角色核心性格特征
2. 检测变化是否与成长弧线一致
3. 添加内心变化描写的过渡
```

---

### 5. 世界观违规（World Rule Violation）

**定义**：内容违反了已建立的世界规则、魔法体系、社会设定等。

**检测方法**：
- 一致性检查器对照 `world_state` 和 `continuity_facts`
- 识别与设定矛盾的能力、规则、社会结构

**修复建议**：
```
请检查内容是否符合世界观设定：
1. 对照已建立的世界规则
2. 识别违规的设定元素
3. 修改违规内容或调整设定
```

---

### 6. 节奏失衡（Pacing Imbalance）

**定义**：叙事节奏过快（赶剧情）或过慢（拖沓）。

**检测方法**：
- EvaluatorAgent 的 `pacing` 维度（0-1）
- 检测场景时长与事件密度的比例

**修复建议**：
```
节奏调整建议：
- 节奏过快：增加场景细节、心理描写、对话
- 节奏过慢：删除冗余描写，加快事件推进
目标：每1000字应有1-2个明确的节奏变化点
```

---

### 7. 情感断裂（Emotional Disconnect）

**定义**：情感从一个状态跳到另一个状态，中间缺乏情绪过渡。

**检测方法**：
- 检测情感词汇密度在段落间的变化率
- 识别情感状态的突变

**修复建议**：
```
情感过渡建议：
1. 在两个情感状态之间添加过渡句
2. 补充内心独白描写心理变化过程
3. 用环境/动作描写暗示情绪变化
```

---

### 8. 重复性问题（Repetition）

**定义**：在用词、句式、情节或情感表达上出现重复。

**检测方法**：
- 词频统计（高频词检测）
- 句式相似度检测
- 情节模式识别

**修复建议**：
```
消除重复：
1. 同义词替换高频重复词
2. 变化句式结构
3. 合并相似情节段落
4. 删除重复的描写内容
```

---

### 9. 信息矛盾（Information Contradiction）

**定义**：同一事实或细节在文本不同位置描述相互矛盾。

**检测方法**：
- 一致性检查器交叉验证 `fact_cards`
- 对照 `continuity_facts` 中的已记录事实

**修复建议**：
```
消除矛盾：
1. 识别矛盾的信息点
2. 确定正确版本（参照已记录的事实）
3. 统一为一致的信息
```

---

### 10. 高潮缺失（Climax Absence）

**定义**：章节缺乏情感或情节的高潮点，读完感到平淡。

**检测方法**：
- TurningPointTracker 检测情节推进力度
- EvaluatorAgent 的 `novelty` 和 `emotional_score` 维度

**修复建议**：
```
增强高潮：
1. 增加冲突强度或情感压力
2. 让主角面临更大的挑战或抉择
3. 补充情绪爆发或关键转折
目标：每个重要章节应有1个明确的情感/情节高潮
```

---

### 11. 对话僵硬（Stiff Dialogue）

**定义**：角色对白不符合其性格、教育背景、身份，或过于书面化。

**检测方法**：
- 对照 `entity_state` 中的角色语言风格
- 检测是否使用角色不适用的词汇

**修复建议**：
```
改写对白建议：
1. 考虑角色的教育背景和性格
2. 加入口语化表达和角色习惯用语
3. 加入肢体语言和情绪暗示
4. 避免所有人都用相同的说话方式
```

---

### 12. 描写空洞（Empty Description）

**定义**：场景或动作描写过于笼统，缺乏具体的感官细节。

**检测方法**：
- 形容词/副词密度检测
- 感官词汇（视觉、听觉、嗅觉等）覆盖率

**修复建议**：
```
丰富描写：
1. 加入具体的视觉细节（颜色、大小、形状）
2. 加入环境音效和气味描写
3. 加入角色的身体感受
4. 使用比喻和拟人增加画面感
```

---

### 13. 伏笔丢失（Dropped Foreshadowing）

**定义**：前文埋下的伏笔在后续没有得到呼应或回收。

**检测方法**：
- 对照 `continuity_facts` 中记录的伏笔
- 检测伏笔关键词在后文出现率

**修复建议**：
```
回收伏笔：
1. 在关键节点让伏笔得到回应
2. 用细节呼应前文的暗示
3. 将伏笔融入情节发展
```

---

### 14. 视角混乱（Perspective Confusion）

**定义**：叙述视角在第三人称/第一人称之间频繁切换，或出现全知视角。

**检测方法**：
- 检测视角代词（我/他/她/它）的使用一致性
- 识别视角切换标记

**修复建议**：
```
统一视角：
1. 选择一个主要视角（建议第三人称有限）
2. 视角切换时添加明确的场景分隔
3. 删除全知视角的"知道"描写
```

---

### 15. 时间线矛盾（Timeline Contradiction）

**定义**：时间顺序混乱，同一事件被描述为不同时间发生。

**检测方法**：
- 对照 `continuity_facts` 中记录的时间线
- 检测时间标记词的一致性

**修复建议**：
```
梳理时间线：
1. 确定故事的基准时间线
2. 统一所有时间标记
3. 删除矛盾的时间描述
```

---

### 16. 背景断裂（Setting Discontinuity）

**定义**：场景切换时缺乏过渡，读者不知道时间/地点已经改变。

**检测方法**：
- 检测场景标记的变化
- 识别缺少过渡句的切换

**修复建议**：
```
流畅过渡：
1. 在场景切换时添加过渡句
2. 用环境描写暗示时间/地点变化
3. 必要时添加时间/地点标记
```

---

### 17. 动机薄弱（Weak Motivation）

**定义**：人物采取行动时缺乏充分的内在或外在动机。

**检测方法**：
- 检测行动前的心理描写
- 对照角色目标与行动的关联度

**修复建议**：
```
强化动机：
1. 补充内心独白说明角色想法
2. 加入外在压力或目标驱动
3. 让决定更符合角色的欲望和恐惧
```

---

### 18. 冲突平淡（Dull Conflict）

**定义**：冲突强度不足，缺乏让读者紧张的对立或压力。

**检测方法**：
- EvaluatorAgent 的 `novelty` 和 `emotional_score` 维度
- 检测冲突双方的力量差距

**修复建议**：
```
增强冲突：
1. 增加对立方的实力或威胁
2. 加入时间压力或后果威胁
3. 让主角面临真正的两难抉择
4. 增加 stakes（赌注）
```

---

### 19. 主题模糊（Theme Ambiguity）

**定义**：章节没有明确的中心主题或信息，读者不清楚作者想表达什么。

**检测方法**：
- 核心主题词密度检测
- 检测是否有明确的信息传递

**修复建议**：
```
强化主题：
1. 明确本章的核心信息或主题
2. 通过情节和对话强化主题表达
3. 让角色选择反映主题内涵
```

---

### 20. 结局仓促（Rushed Ending）

**定义**：章节或故事结尾处理粗糙，缺乏适当的收束。

**检测方法**：
- 检测结尾长度与前文比例
- 识别缺少收尾描写的结尾

**修复建议**：
```
完善结尾：
1. 添加情感收束的描写
2. 让主要冲突有明确的解决或升级
3. 加入角色对事件的反应
4. 必要时添加承上启下的过渡句
```

## 与 EvaluatorAgent 的协作

RealtimeEditor 接收来自以下来源的反馈：
1. **EvaluatorAgent** — 评估分数和建议
2. **ConsistencyChecker** — 一致性问题列表
3. **TurningPointTracker** — 转折点追踪笔记

所有问题统一为 `modifications` 列表后，调用 LLM 执行批量修改。
